# Muhammed Shibili Jasir — Next.js Property Consultant Website

A responsive Next.js 15 + React 19 website with Framer Motion reveal animations, animated hero content, hover interactions, mobile navigation, and a WhatsApp enquiry form.

## Run locally

1. Install Node.js 20.9 or newer.
2. Extract this folder and open it in VS Code.
3. Open the terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Build for production

```bash
npm run build
npm run start
```

## Deploy

Recommended: deploy the project to Vercel by importing the project repository. This is a Next.js app, so it cannot be deployed by uploading the source files to a basic static `public_html` folder without building/exporting it. For Hostinger, use a hosting plan that supports Node.js applications and follow Hostinger's current Next.js/Node.js deployment workflow.

The enquiry form opens WhatsApp with a prefilled message. It does not save leads to a database.
